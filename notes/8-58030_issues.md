# 8-58030 issues (Grazer G2018D, October 1994)

Transcribed 2026-11-17: 43 sections, 1,058 rows, schema `lookup-v1.1`, `coverage: partial`. Defaults below were applied without stopping to ask.

## 1. Index vs table
This book has **no numerical index**. The table of contents (printed p21) lists the parts-list sections only, and the operator's manual has only an alphabetical subject index. So there is nothing to compare, and there are **no index-vs-table differences**. As a substitute I compared every page's part numbers with the OCR draft; every difference was an OCR misread.

## 2. Missing sections (set in `missingSections[]`)
The brief expected two gaps. There are **five**. Printed pages 42-43 are missing from the PDF as well (PDF p45 = printed 41, PDF p47 = printed 45):
- Exhaust System (engine), Fuel System (tractor) and Exhaust System (tractor): all listed at printed p43.
- 52" Mower Drive (printed p83) and Gear Box (Mower) (printed p89), as expected. PDF pp88-90 are blank.

The 62" mower drive (printed p87) says "see page 85" for gear box service, while the table of contents puts Gear Box (Mower) on p89. Kept as printed. 8-3500 or 8-58040 may fill the 52" drive and gear box if you agree.

## 3. Serial breaks
Only one, confirmed by eye on every table page: the **62" mower drive** (printed p87). `*` = use before S/N 013306063, `**` = use S/N 013306063 and after. Stored as serial variants (before: `serialTo 013306062`; after: `serialFrom 013306063`) on refs 7, 8, 10, 23 and 24 (ref 24 swaps C37557 for 113-268). The tractor itself has no serial info (blank ID page), so it matches all serials. The 52" deck pages have no break.

## 3a. Section map
All sections `appliesTo: ["G2018D"]` with no section-level serial constraint. Engine = printed pp23-57, tractor = pp59-79, decks = pp81 (52") and pp85-87 (62"). The 62" drive is the only section with `variantBasis: serial`; its gear box ref 18 also carries component variants (Curtis C37898 / Superior C42775).

## 4. Check items (table value kept in every case)
- **Electrical ref 18 vs clutch page:** PTO clutch is C37511 on the electrical page but C37569 on the electric clutch page. Both kept and flagged.
- **113-1 on engine mounts ref 4** is described as a 1/2" - 13 x 1-1/4" bolt (113-1 is the 1/4" - 20 x 1/2" bolt elsewhere; 113-417 is the 1/2" - 13 x 1-1/4" bolt). **113-1 on the 52" deck ref 30** is described as 1/4" - 20 x 1" (113-4 is the 1" bolt). **131-1 on the fan assembly ref 31** is probably 113-1 (bolt 1/4" - 20 x 1/2").
- **193-1001** prints as NUT 1/4" - 28 (steering ref 18) and NUT 1/4" - 20 lock (transmission controls ref 6).
- **113-2419** (1/2" - 13 x 6-1/2" bolt) prints with four digits on both decks, so it is probably a misprint, but identical in both places.
- **Tail wheel tire qty 8** (C37857) under a 1-wheel assembly. Kept and flagged.
- **PIN - deck C10821** has qty 1 on the 52" deck and qty 2 on the 62" deck (possible, as printed).
- **Electric clutch page:** handwritten note on this scan, "MAG STOP SUBSTITUTION CLUTCH IS WARNER'S #5218-27" (the 8 may be a 9). It is in the section note, not a part row.
- **Hydraulic lift:** ref 26 is not printed (list runs 25 to 27). **Base and lift arms:** ref 11 printed as "1", corrected. **Typo corrected:** "CIPCLIP" to CIRCLIP (camshaft case ref 36). REQ'D is out of register on the electrical page only (42 rows mapped in sequence, flagged inferred qty).
- Descriptions differ slightly for the same part number in many places (for example C37910 "anti-scalp" on the 52" deck vs "anti-skid" on the 62" deck); kept as printed.

## 5. Weight box and wheel weights
The book lists **no weight box and no wheel weights**. It prints a body "PLATE - weight" C45299 x4 (body ref 2) and "60 lb. Rear Frame Weight" under standard features on the specification page. I did **not** add attachments for either, because they are standard equipment on the tractor. Say if you want a weight entry added.
